# Contribuir

Use Node.js atualizado, rode `npm run check` e faça uma alteração útil por contribuição. Descreva o problema, o comportamento resultante e a validação. Inclua testes para conflitos, persistência ou regras de validação que você mudar.

Não faça commits vazios, fracionamento artificial de alterações nem mudanças sem utilidade para aumentar contadores. Contribuições assistidas por IA precisam passar pela mesma revisão e pelos mesmos testes.

Não adicione dados pessoais, fotos de pessoas, documentos, credenciais, `.env`, bancos, logs ou código de projetos privados. Exemplos devem ser sintéticos e claramente identificados. Dependências, se necessárias, precisam de justificativa, licença compatível e lockfile revisado.

O servidor permanece local até existir um desenho e uma implementação completos de autenticação e autorização. Não remova essa restrição como atalho para uma implantação.
